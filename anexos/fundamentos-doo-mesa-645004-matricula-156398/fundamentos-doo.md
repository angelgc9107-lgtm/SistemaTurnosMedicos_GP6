# Anexo - Fundamentos del Diseño Orientado a Objetos

---

El paradigma orientado a objetos organiza el software mediante clases y objetos que representan entidades del dominio del problema. Este enfoque facilita el análisis, el diseño y la construcción de sistemas al modelar tanto los datos como los comportamientos asociados a cada objeto.

En este anexo se desarrollan los cuatro principios fundamentales del Diseño Orientado a Objetos: abstracción, encapsulamiento, herencia y polimorfismo. Cada uno de ellos se explica utilizando ejemplos tomados del proyecto **Sistema de Turnos Médicos**, con el objetivo de mostrar cómo estos conceptos fueron aplicados durante el desarrollo del sistema.
